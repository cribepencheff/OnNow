# Design

The visual design reference for On Now, for the Design phase. The app is
dark only (ADR 0011).

| File | What it is |
| ---- | ---------- |
| `design-system.md` | The design system as text: colour, type, shape, imagery, icons and the chosen Home direction (B) |
| `tokens.json` | The design tokens: colours, type styles, spacing and radii |

Both files are exported from the design work in Claude. They are the text
version of the links below, so the repository and Claude Code share the
same reference. Change the design there first, then export these files
again.

Links for the owner:
- Design system "On Now":
  https://claude.ai/artifact/DY7sH6WJGi65vCKWjXER4k
- Design canvas "On Now Home" (Home direction A vs B, image tests):
  https://claude.ai/artifact/RCHSSp7X2YsGy25ykVGnPc
